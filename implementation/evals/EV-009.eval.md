# Eval — EV-009

```
Tipo   : salida
Origen : spec (principio 2 de la constitución: el build no depende de una red)
Cubre  : el sitio construye sin ninguna credencial de Google en el entorno
Creado : 2026-09-03
```

---

## Comando

```bash
node implementation/evals/checks/build-sin-credenciales.mjs
```

## Caso

**Precondición**
Ninguna. El check borra `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GOOGLE_REFRESH_TOKEN`,
`GBP_ACCOUNT_ID`, `GBP_LOCATION_ID` y `GBP_PROFILE_URL` del entorno **del proceso hijo**
antes de construir, así que da igual lo que tenga la máquina donde se ejecute.

**Entrada**
`npm run build` con el entorno limpio.

**Salida esperada**
Exit 0 y el resumen de rutas de Next. El build no puede pedir credenciales, no puede
llamar a Google y no puede fallar por no tenerlas.

**Qué NO debe pasar**
- Que el build intente una petición de red a `oauth2.googleapis.com` o
  `mybusiness.googleapis.com`.
- Que falle con `undefined` al leer una variable ausente.
- Que se quede colgado esperando un token.

---

- [x] Ejercita el mismo comando que ejecuta el CI y que ejecutará Cloudflare Pages
