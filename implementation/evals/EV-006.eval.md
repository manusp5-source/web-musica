# Eval — EV-006

```
Tipo   : trayectoria
Origen : spec (criterio de éxito de intent-001, checklist de M1-UJ-004)
Cubre  : ningún secreto de OAuth llega al bundle que recibe el navegador
Creado : 2026-09-03
```

---

## Comando

```bash
node implementation/evals/checks/no-secrets.mjs
```

## Caso

**Precondición**
Existe un build de producción en `.next/` (`npm run build`). El eval falla con mensaje
explícito si no lo hay: comprobar un build que no existe siempre «pasa», y eso es
exactamente el fallo que este proyecto ya se ha comido una vez.

**Entrada**
El árbol `.next/` completo, saltando `cache/` (no se publica) y los ficheros binarios.

**Salida esperada**
```
Sin secretos en .next/ (4 nombres y 0 valores comprobados).
```
Exit 0.

**Qué NO debe pasar**
Que aparezca `client_secret`, `refresh_token`, `GOOGLE_CLIENT_SECRET` o
`GOOGLE_REFRESH_TOKEN` en cualquier fichero servible. Si las variables están presentes en
el entorno, también se busca **su valor literal** — el nombre puede no aparecer y el valor
sí, que es la fuga de verdad.

- [x] Comprueba el artefacto que se publica (`.next/`), no el código fuente
- [x] Falla si no hay build, en vez de dar un verde vacío
- [x] Escrito en Node, no en `grep`: el runner puede lanzarse desde PowerShell
- [ ] Se ejecuta en CI (pendiente de `gh auth login` → B-03)
