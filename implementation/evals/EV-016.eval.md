# Eval — EV-016

```
Tipo   : salida
Origen : spec (intent-002, M2-UJ-002)
Cubre  : el QR generado decodifica a la URL correcta; el destino sin URL real se omite de verdad
Creado : 2026-09-10
```

---

## Comando

```bash
node implementation/evals/checks/qr-round-trip.mjs
```

## Caso

**Entrada**: `npm run qr` ejecutado de verdad como proceso hijo (no simulado), contra el
`site.ts` real del repo.

**Salida esperada**
```
QR "web" → decodifica a "https://violagranada.es", ...B, resolución suficiente.
QR "review" correctamente omitido: no hay profileUrl todavía.
Límite declarado: esta comprobación es un decodificador de software, no una prueba de escaneo en papel real.
```
Exit 0.

**Qué comprueba**
1. `assets/qr/web.svg` existe y es vectorial de verdad (`<svg>` + `<path>`, no una imagen
   incrustada disfrazada de SVG).
2. `assets/qr/web.png` decodifica —con `jsqr` + `pngjs`, un lector de QR real, no una
   comparación de bytes— **exactamente** a `site.domain`, extraído de `site.ts` por regex.
3. El PNG mide ≥ 600 px de lado (el mínimo del criterio de éxito: 5 cm a 300 ppp).
4. El destino «review» **no generó ningún fichero**, ni SVG ni PNG — la omisión es real,
   no solo un mensaje por consola.
5. Nada se escribió en `public/`.

**Qué NO debe pasar**
- Que el PNG decodifique a una URL distinta de `site.domain`.
- Que un destino con placeholder deje ficheros a medias.
- Que el generador escriba fuera de `assets/qr/`.

---

## El límite de esta comprobación, declarado sin rodeos

**No hay impresora ni cámara en esta máquina.** El criterio de éxito real de
`intent-002` es *«un móvil escanea el PNG impreso a 2 cm de lado desde 20 cm»* — una
prueba física que este eval no puede hacer. Lo que sí hace, y es un round-trip real, no
una aproximación: genera con el script de producción, decodifica el resultado con
software, y confirma que la URL vuelve intacta. Un módulo mal impreso, tinta de bajo
contraste o una distancia de lectura real distinta de la simulada **no los detecta esto**.
La prueba física la hace Manuel con el SVG en una impresora de verdad.
